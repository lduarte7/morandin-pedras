# Morandin Pedras & Marmoraria

Protótipo de alta fidelidade — direção **Monolithic Editorial**.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS 4
- Framer Motion
- `next/image` + `next/font` (Cormorant Garamond + Manrope)

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
